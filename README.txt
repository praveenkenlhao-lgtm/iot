IoT HTML/CSS Slides

เปิด index.html ในเว็บเบราว์เซอร์เพื่อดูสไลด์ 16 หน้า

การนำเสนอ
- ใช้ปุ่มลูกศร หรือแป้น ← / → เพื่อเปลี่ยนหน้า
- กด “เต็มจอ” สำหรับนำเสนอ
- กด “ดาวน์โหลด PDF” เพื่อบันทึกไฟล์ PDF 16 หน้า

การแก้ไขภายหลัง
- แก้ข้อความใน index.html
- ปรับสี ขนาด และตำแหน่งใน styles.css
- เก็บโฟลเดอร์ assets และไฟล์ PDF ไว้ข้าง HTML
